# Analog Clock with CSS and Python

A simple responsive analog clock built with:

- Python
- Flask
- HTML
- CSS
- JavaScript

## Features

- Real-time analog clock
- Hour, minute, and second hands
- 12-hour clock face
- Minute markers
- Responsive design
- CSS styling
- No external libraries required for the frontend
